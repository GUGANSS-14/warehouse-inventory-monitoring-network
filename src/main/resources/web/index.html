CHAPTER 01
🏢 Project Overview & Core Mission

The Warehouse Inventory Monitoring Network (WIMN) is an enterprise-grade cyber-physical system integrating a 3D WebGL Digital Twin, an IoT Star Topology Network, and a Real-Time Warehouse Management System (WMS). It replicates the physical operations of the Sector-04 automated logistics depot, bridging high-bay storage racks with live network traffic visualization, automated guided vehicles (AGVs), RFID sensor gates, and manual override consoles.

Facility Scope
Sector-04 Central Depot with 4 High-Bay Racks (A1, B2, C3, D4) and automated airlock.
Network Architecture
Star Topology with central 10Gbps Core Switch and Core Server backbone.
Visual Engine
Three.js WebGL with orbital 360° controls, raycasting HUD, and conduit packet bursts.
Sound & Voice
Web Audio API 4-profile synthesizer & Web Speech API contextual robotic narrator.
CHAPTER 02
🌐 Star Topology Network Architecture & Segmented VLANs

The facility is organized as a resilient Star Topology where every scanning station, workstation, RFID reader, and CCTV node connects directly to the Central Core Switch (SW-CORE-01) and Central Server (SRV-MAIN-01). To guarantee high throughput and security isolation, traffic is segmented across 4 distinct Virtual Local Area Networks (VLANs):

  • VLAN 10 — Receiving & Inbound Intake: Barcode Scanner (SCN-RCV-01), Workstation (WS-RCV-01), and Switch (SW-RCV-01). Dedicated to newly arrived supplier shipments and put-away registration.
  • VLAN 20 — Storage Racks & Aisle Monitoring: High-Bay RFID Gate Antennas (RFID-STR-01) and Switch (SW-STR-01). Continuously monitors stock levels across Racks A1, B2, C3, and D4.
  • VLAN 30 — Outbound Dispatch & Fulfillment: Dispatch Workstation (WS-DSP-01) and Switch (SW-DSP-01). Validates catalog inventory, processes customer pick orders, and routes dispatch packets.
  • VLAN 40 — Facility Security & Perimeter: Surveillance Cameras (CAM-SEC-01) and Security Switch (SW-SEC-01). Streams RTSP video and security airlock telemetry.

Protocol Implementation: Supports TCP connection-oriented handshakes with SYN/ACK verification, UDP high-frequency sensor datagrams, ICMP echo ping probes with hop-by-hop latency measurement, and CRC-32 checksum error checking with operator single-bit inversion testing.

CHAPTER 03
🏢 3D Warehouse Digital Twin & WebGL Conduits

Powered by Three.js (WebGL), the 3D Digital Twin renders a photorealistic spatial model of the automated facility:

  • 4 High-Bay Steel Racks: Distinct warehouse storage bays: Rack A1 (Electronics), Rack B2 (Hardware), Rack C3 (IoT Sensors), and Rack D4 (Packaging & Materials).
  • Real-Time Network Conduits: Illuminated overhead fiber conduits visually project flowing packet particles in 3D whenever network transmissions occur between workstations and the central server cage.
  • Orbital 360° Camera & Preset Perspectives: Includes presets for Isometric Overview, High-Bay Racks, Receiving Dock, Server Cage Infrastructure, and individual rack zooms. Clicking any 3D Rack Card smoothly glides and refocuses the camera directly onto that rack bay.
  • Raycasting Telemetry HUD: Mouse hovering over 3D racks or network nodes projects dynamic spatial tooltips showing zone identity, inventory counts, and operational parameters.
CHAPTER 04
🛠️ Operator Manual Override Console (Workstations & Simulation)

The full-width Operator Manual Override Console provides warehouse supervisors with 5 specialized interactive control desks:

  • Tab 1: Packet Dispatcher & Ping: Manual transmission of custom packets across source/destination nodes, protocols (TCP, UDP, ICMP), payload templates, checksum bit-flip injection, and calculated hop-by-hop route visualization.
  • Tab 2: Inbound Intake & Outbound Order Fulfillment: Symmetrical dual-workstation desk:
    • Inbound Intake: Registers new goods, assigns product categories, targets rack bays, supports quick batch quantity preset pills (+10, +25, +50, +100), valuation pricing, and carrier selection.
    • Manual Outbound Order Fulfillment: Processes order dispatches, selects priority tiers (Standard, Express, Critical), supports quantity presets (1, 5, 10, 25), selects dispatch gates, and performs live inventory unit deduction.
    • 4-Bay Storage Utilization Meter: Real-time occupancy meters reflecting live unit counts and storage capacities for Racks A1 through D4.
  • Tab 3: Link & Device Fault Simulator: Enables live hardware testing by cutting power to individual network switches/servers or severing trunk optical cables to observe topology failover.
  • Tab 4: Facility Alarm & AGVs: Triggers emergency facility-wide lockdown with warning sirens and deploys Autonomous Guided Vehicles (AGVs) on warehouse aisle transport runs.
  • Tab 5: Simulation Engine Controls: Allows operators to pause/resume background traffic generation, synchronize clocks, and fire 20-packet high-density traffic bursts into the core switch.

CHAPTER 08
⚡ Full-Stack Backend Architecture & REST APIs

The backend engine runs an embedded Java HTTP server backed by SQLite database persistence:

  • Embedded Web Server (WarehouseWebServer.java): High-performance lightweight HTTP server operating on port 8080, serving live development assets directly from the filesystem.
  • REST API Surface:
    • GET /api/inventory: Fetches all catalog SKUs, quantities, valuations, and rack coordinates.
    • GET /api/devices: Returns online/offline status, IP addresses, MAC addresses, and VLANs for all 18 devices.
    • GET /api/topology: Exposes nodes, coordinates, and link statuses for the star network graph.
    • GET /api/metrics: Provides real-time simulation clock, hop latency, packet delivery ratio (PDR), and bandwidth utilization.
    • GET /api/events: Streams live operational and network audit logs.
    • GET /api/action/*: Handles stock intake, outbound dispatch, power toggling, cable cut simulation, packet injection, and simulation engine controls.
  • Database Architecture (DatabaseManager.java): SQLite relational database with Write-Ahead Logging (WAL) storing persistent tables for inventory, network devices, and event history.
